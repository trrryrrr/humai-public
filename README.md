# アカデミックAI急進度診断

研究者・大学生・大学院生・アカデミック関係者向けに、AI時代の研究スタイルに対する態度を可視化するローカルWebアプリです。4つの対照的な軸からMBTI風のタイプコードを出し、同時に0〜100点の「AI急進度スコア」を表示します。

診断は50問の質問プールから毎回20問を抽出して実施します。個人情報は取得せず、診断完了後の結果データだけを保存し、統計画面で傾向を確認できます。

共有集計用のAPIを設定した場合は、複数のブラウザや端末から送信された結果をまとめて集計します。APIを設定しない場合は、従来どおり各ブラウザのlocalStorageだけに保存されます。

## ローカルでの起動方法

```bash
npm install
npm run dev
```

## ビルド方法

```bash
npm run build
```

共有集計APIを使う場合は、ビルド時に `VITE_RESULTS_ENDPOINT` を指定してください。

```bash
VITE_RESULTS_ENDPOINT="https://example.com/results" npm run build
```

GitHub Pages向けに `/humai-public/` 配下で公開するビルドは次で確認できます。

```bash
npm run build:pages
```

公開URLは GitHub Pages のデプロイ完了後、通常は次になります。

```text
https://trrryrrr.github.io/humai-public/
```

## 診断軸

- C / A：AGI前提度。AGIや急速なAI発展を、研究計画・キャリア設計・大学院教育・分野選択の前提にどれくらい入れているか。
- T / N：AIネイティブ度。AIを翻訳・要約・文章修正などの補助ツールとして使うのか、研究プロセス全体に組み込むのか。
- H / D：認識委譲度。仮説生成、探索、検証、優先順位づけ、暫定判断をどこまでAIに委ねられると考えるか。
- P / R：制度再設計度。論文、査読、著者性、研究評価、研究室、大学院教育などの学術制度をAI前提で変えるべきと考えるか。

## 質問抽出ロジック

- 50問プールから各軸5問、合計20問を抽出します。
- 各軸では `radical` 方向の質問を2問以上、`traditional` 方向の質問を2問以上含めます。
- 残り1問はその軸の未選択質問からランダムに選びます。
- 選ばれた20問はシャッフルして表示します。
- 診断を開始するたびに新しい20問セットを抽出し、診断中はそのセットを固定します。

## 採点ロジック

各質問は1〜5の5段階評価です。質問ごとに `direction` を持ち、回答から0〜100点の itemScore を計算します。

- `direction: "radical"`：`itemScore = ((answer - 1) / 4) * 100`
- `direction: "traditional"`：`itemScore = ((5 - answer) / 4) * 100`

軸スコアは、その軸に属する5問の itemScore 平均です。軸スコアが50以上ならAI急進側の文字、50未満なら伝統側の文字を採用します。総合AI急進度スコアは4軸スコアの平均です。

## 保存データ

API未設定時は、localStorageのキー `academic_ai_radicality_results` に最新100件の結果のみ保存します。API設定時は、同じ形式の結果データを `VITE_RESULTS_ENDPOINT` に送信し、統計画面ではそのAPIから取得した結果を表示します。通信に失敗した場合は、このブラウザ内のlocalStorageをフォールバックとして使います。

保存するデータは以下だけです。

- 完了日時
- 総合スコア
- タイプコード
- 4軸スコア
- 4軸の採用文字
- スコア帯

名前、メールアドレス、所属、年齢、性別、位置情報、IPアドレス、ブラウザ情報、個別回答、選ばれた質問ID、質問文、自由記述は保存しません。

共有集計APIには、次の最小インターフェースを用意してください。

- `GET`：`ResultRecord[]` または `{ "results": ResultRecord[] }` をJSONで返す
- `POST`：`ResultRecord` をJSONで受け取り、保存する
- CORS：公開ページのURLからの `GET` / `POST` を許可する
- 保存対象：上記のResultRecordのみ。個別回答、質問ID、質問文、自由記述、個人識別情報は保存しない

## 統計画面

統計画面では、保存済み結果数、平均スコア、中央値、最高点、最低点、4軸平均、スコア帯分布、タイプコード別ランキング、各軸でAI急進側になった割合、最新100件のスコア推移を表示します。共有集計APIが設定されている場合は共有統計、設定されていない場合はこのブラウザ内の統計として表示します。

この端末のlocalStorageに保存された統計データは「この端末の統計データを削除する」ボタンから削除できます。共有集計API側のデータ削除は、利用するバックエンド側で管理してください。
